## Atividade Lógica de Programação
Criando uma classe para representar um héroi em um jogo genperico

### Tecnologias Utilizadas
- Node.js (TypeScript)
- Git e Github
- VS Code

## Objetivo
Esse foi uma atividade do curso lógica de programação na DIO a respeito de classes

### Como executar
1. Clonar Repositório
```bash
    git clone https://github.com/martiniclayton/classes-logica.git
    cd classes-logica
```
2. Instale as Dependências
```bash
    npm install
``` 
3. Rodar o Projeto
```bash
    node src/index.ts
```

### Funcionalidades
Montando uma classe para representar um heroi, contendo atributos e método de atacar.
